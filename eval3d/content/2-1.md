## 二、學校現況說明

本校積極爭取原住民族委員會、教育部、縣政府、鄉公所等各方資源，持續擴充文化學習環境並改善校園設施。

### （一）文化學習場域

本校校園保留山林自然風貌，逐年與部落耆老合作建置泰雅傳統建築群，活化校園空間，供小米播種祭（Smgatu）、祖靈感恩祭（Cmyus）儀式及文化課程實作使用，並針對現有傳統建築進行修繕，提升使用效率與安全性。

<table header-row="true">
| 場域 | 主要教學用途 |
| 小米田 | 七年級燒墾管理、開墾播種、摘穗打米；小米生命週期貫穿歲時課程 |
| 苧麻園 | 八年級苧麻栽植管理、刮麻製線與染線之原料來源 |
| 傳統家屋 | 傳統建築工法教學；祭儀與文化課程情境學習場域 |
| 傳統穀倉 | 九年級傳統建築單元，由耆老到校與學生共作 |
| 瞭望台 | 傳統聚落空間結構之教學展示 |
| 工寮 | 七年級工寮搭建與三石灶實作；戶外課程據點 |
| 文化廊道 | 傳統地機編織等技藝課程之操作場域；學生文化作品成果展示 |
| 青年學習場域 | 文化課程共作、成果展示、祭儀場域與部落活動使用 |
</table>

上述傳統建築場域不僅作為文化課程之重要教學載體，更使校園具備泰雅微型部落之功能。場域建置與修繕主要透過「112 泰雅傳統家屋維護整修計畫」及「112、115 年度營造原住民族文化學習場域實施計畫」爭取經費辦理。

### （二）學習設備

本校持續透過原民會及縣府實驗教育補助計畫，逐年規劃資本門經費添購教學輔助設備，配置涵蓋課前備課、課中數位教學、課後省思紀錄，以及田野調查、校外活動拍攝紀錄與成果展示等面向。

<table header-row="true">
| 資本門設備 | 說明 | 經費來源 |
| 固定式投影機 | 架設於教室，供日常課程教學使用，提升教材呈現之清晰度與教學效率 | 112 學年度實驗教育計畫 |
| 口袋雲台相機 | 供教學影片拍攝、田野調查拍攝等用途，完整記錄課程歷程與文化踏查現場 | 112 學年度實驗教育計畫 |
| 行動式投影機 | 供學生展演、部落宣傳活動及成果發表等場合機動使用 | 112 學年度推動實驗計畫 |
| 數位相機 | 供課程活動影像紀錄使用，留存教學歷程，作為課程檢討與成果彙整之依據 | 113 學年度實驗教育計畫 |
| 雙頻道手提式無線擴音機 | 供部落踏查、戶外活動及祭儀辦理等場合使用，確保戶外教學語音傳達清晰 | 113 學年度推動實驗計畫 |
| 可移動式智慧液晶顯示器 | 於課程進行時播放細部教學影片，並兼作校外成果展示之載具 | 114 學年度實驗教育計畫 |
| 筆記型電腦 | 供文化教師於課前備課、課中數位教學及課後省思紀錄使用 | 114 學年度推動實驗計畫 |
</table>

上述設備均已辦理財產增加程序並列冊管理，透過軟硬體設備之逐步充實，使文化教師得以結合數位影音資源進行教學，同時完整保存課程歷程紀錄。

### （三）校園設施改善

本校總務處積極爭取縣府工程補助，持續維護與改善校園基礎環境，以確保師生學習與生活之安全與舒適。本評鑑期間執行之工程涵蓋排水工程改善、廚房設施更新、老舊廁所整修、屋頂防水隔熱工程、飲用水設備改善、防災校園建置以及災損復建等。上述設施之改善有助於校園整體學習環境之提升，亦間接支持文化課程於校園各場域之順利實施。（各項工程之核定金額與主責處室詳見 <mention url="https://app.notion.com/p/3c81d191518e81a6b245efdf2c2f3cb6" />）
